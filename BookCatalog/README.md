# Book Catalog

Простой веб-приложение для управления каталогом книг с полным CRUD функционалом.

## Технологии

- **ASP.NET Core 8 MVC**
- **Entity Framework Core 8**
- **SQLite**
- **Bootstrap 5**

## Требования

- .NET 8 SDK
- Visual Studio 2022 или VS Code

## Запуск проекта

### Способ 1: Visual Studio

1. Откройте проект в Visual Studio
2. Нажмите **F5** или кнопку **Run**
3. Откроется браузер на `https://localhost:5000`

### Способ 2: Командная строка
```bash
# Восстанавливаем зависимости
dotnet restore

# Запускаем проект
dotnet run

# Откройте в браузере
# https://localhost:5001
